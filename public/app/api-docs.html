OTP API — Developer Docs

Programmatically buy numbers and receive OTPs. Every user has a personal API key.

Authentication

Send your key on every request via the header Authorization: Bearer <API_KEY> or query param ?api_key=<API_KEY>.

Base URL: (auto-detect) · Versioned under /api/v1

No key yet? Generate one on the Account page.

1. Buy a number
2. Use it on your target service
3. OTP is pulled automatically
4. GET /otp → receive the code

Response format

Success: { "success": true, ... }  ·  Error / still pending: { "success": false, "error" / "message": "...", "status": "pending|expired|..." }. While OTP is not yet available, /otp keeps returning success:false with status:"pending" — keep polling until status:"completed".

Rate limits

Limits are enforced per API key (+ IP) over a sliding 60-second window. Exceeding them returns 429 { "success": false, "error": "..." } with a Retry-After header.
